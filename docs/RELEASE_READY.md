## 🔧 Установка

### Вариант 1: Установочник (рекомендуется)

1. Запустите `AuF Network Tools-1.0.0-Setup.exe`
2. Выберите папку установки (по умолчанию: `C:\Program Files\AuF Network Tools`)
3. Дождитесь завершения установки
4. Приложение запустится автоматически
5. Ярлыки созданы на рабочем столе и в меню Пуск

### Вариант 2: Портативная версия

1. Скопируйте `AuF Network Tools-1.0.0-Portable.exe` в любую папку
2. Запустите exe файл
3. Готово! Настройки сохраняются рядом с exe

## 🎯 Первый запуск

1. Приложение откроется на Dashboard
2. Кликните на любую карточку инструмента
3. Наслаждайтесь плавными анимациями!
4. Проверьте Speed Test в "Сетевые утилиты"

## 🐛 Известные особенности

- Антивирусы могут блокировать установочник (ложное срабатывание)
  - Решение: Добавьте в исключения или используйте портативную версию
- Speedtest.net заблокирован в России
  - Решение: Используем Яндекс.Интернетометр подход (уже реализовано)
- Первый запуск может занять 2-3 секунды

## 📝 Деинсталляция

### Установленная версия:
1. Откройте "Установка и удаление программ" в Windows
2. Найдите "AuF Network Tools"
3. Нажмите "Удалить"

### Портативная версия:
- Просто удалите exe файл и папку с настройками
