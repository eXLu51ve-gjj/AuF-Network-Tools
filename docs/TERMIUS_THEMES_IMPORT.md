## 🔧 Технические детали

### Структура темы

Каждая тема содержит 27 цветовых параметров:

```typescript
{
  id: string;              // Уникальный идентификатор
  name: string;            // Название темы
  description: string;     // Описание на русском
  
  // Основные цвета
  background: string;      // Фон терминала
  foreground: string;      // Основной текст
  cursor: string;          // Курсор
  
  // Семантические цвета
  prompt: string;          // Промпт (user@host)
  command: string;         // Команды
  output: string;          // Вывод команд
  error: string;           // Ошибки
  info: string;            // Информация
  success: string;         // Успех
  warning: string;         // Предупреждения
  
  // Специальные элементы
  ip: string;              // IP адреса
  mac: string;             // MAC адреса
  port: string;            // Порты
  number: string;          // Числа
  keyword: string;         // Ключевые слова
  
  // Файловая система
  path: string;            // Пути
  file: string;            // Файлы
  directory: string;       // Директории (bright blue!)
  link: string;            // Символические ссылки
  executable: string;      // Исполняемые файлы
  permissions: string;     // Права доступа
  
  // Метаданные
  user: string;            // Пользователь
  group: string;           // Группа
  date: string;            // Дата
  size: string;            // Размер файла
}
```

### Интеграция с LS_COLORS

Все темы правильно работают с автоматической настройкой `LS_COLORS`:

```bash
# Автоматически устанавливается при подключении
export LS_COLORS="di=1;34:ln=1;36:ex=1;32:*.tar=1;31:..."
```

## 🚫 Почему не удалось извлечь темы из Termius

### Технические ограничения:

1. **IndexedDB в бинарном формате**
   - Темы хранятся в `C:\Users\nml52\AppData\Roaming\Termius\IndexedDB`
   - Формат: LevelDB (бинарный)
   - Требуется специальный парсер

2. **app.asar запакован**
   - Electron архив с кодом приложения
   - Можно распаковать, но темы в коде, не в конфиге

3. **DevTools отключены**
   - F12 не работает в production сборке
   - Нельзя посмотреть IndexedDB через браузер

4. **Preferences.json минимален**
   - Содержит только базовые настройки (spellcheck)
   - Темы не экспортируются в JSON

### Альтернативные решения:

✅ **Использовать популярные темы** (что мы и сделали)  
✅ **Добавить пользовательский редактор** (уже есть в UI)  
❌ Парсить IndexedDB (слишком сложно)  
❌ Распаковывать app.asar (темы в коде, не данные)

## 📝 Как использовать новые темы

1. Откройте SSH терминал
2. Нажмите на вкладку **"Темы"** в правой панели
3. Прокрутите список тем
4. Выберите любую из 10 доступных тем
5. Тема применится мгновенно ко всем активным терминалам
