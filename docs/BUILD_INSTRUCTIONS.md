# Инструкция по сборке AuF Network Tools

## Требования

- Node.js 18+ 
- npm или yarn
- Windows (для сборки Windows установочника)

## Шаги сборки

### 1. Установка зависимостей

```bash
npm install
```

### 2. Сборка приложения

```bash
npm run build
```

Эта команда:
- Компилирует TypeScript (main process)
- Собирает React приложение (renderer process)
- Копирует ресурсы

### 3. Создание установочника

#### Windows (NSIS Installer + Portable)

```bash
npm run package:win
```

Создаст:
- `release/AuF Network Tools-1.0.0-Setup.exe` - установочник
- `release/AuF Network Tools-1.0.0-Portable.exe` - портативная версия

#### Только установочник

```bash
electron-builder --win nsis --x64
```

#### Только портативная версия

```bash
electron-builder --win portable --x64
```

### 4. Тестирование перед сборкой

```bash
npm run dev
```

## Структура выходных файлов

```
release/
├── AuF Network Tools-1.0.0-Setup.exe       # Установочник (NSIS)
├── AuF Network Tools-1.0.0-Portable.exe    # Портативная версия
└── win-unpacked/                           # Распакованная версия для тестирования
```

## Настройки установочника (NSIS)

- **Язык:** Русский (1049)
- **Тип установки:** С выбором папки (не OneClick)
- **Ярлыки:** Рабочий стол + Меню Пуск
- **Запуск после установки:** Да
- **Удаление данных при деинсталляции:** Нет

## Размер установочника

- Установочник: ~100-150 MB (сжатие maximum)
- Установленное приложение: ~200-250 MB

## Иконка приложения

Иконка находится в `build/icon.png` (256x256 или больше)

## Подпись кода (опционально)

Для подписи установочника нужен сертификат:

1. Получите сертификат (.pfx)
2. Установите переменные окружения:
   ```
   set CSC_LINK=path/to/certificate.pfx
   set CSC_KEY_PASSWORD=your_password
   ```
3. Соберите с подписью:
   ```bash
   npm run package:win
   ```

## Автообновление (опционально)

Для включения автообновлений:
1. Настройте GitHub Releases или другой сервер
2. Обновите `publish` в `electron-builder.json`
3. Используйте `electron-updater` в коде

## Отладка сборки

Если возникают проблемы:

```bash
# Подробный вывод
DEBUG=electron-builder npm run package:win

# Очистка кэша
npm run build
rm -rf release
npm run package:win
```

## Проверка установочника

1. Запустите `AuF Network Tools-1.0.0-Setup.exe`
2. Выберите папку установки
3. Дождитесь завершения установки
4. Приложение запустится автоматически
5. Проверьте ярлыки на рабочем столе и в меню Пуск

## Деинсталляция

- Через "Установка и удаление программ" в Windows
- Или через `uninstall.exe` в папке установки

## Примечания

- Первая сборка может занять 5-10 минут
- Последующие сборки быстрее (~2-3 минуты)
- Для сборки нужно ~2 GB свободного места
- Антивирусы могут блокировать установочник (ложное срабатывание)
